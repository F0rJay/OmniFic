# OmniFic 使用指南

> 最后更新：2026-07-29 · 适用于 OmniFic 0.8.1

本指南面向第一次使用 OmniFic 的创作者，介绍如何从空白项目开始写作、导入旧稿、维护角色与世界书，并让 Agent 在可控权限下参与创作。

安装、更新、数据备份和彻底卸载请参阅[安装与卸载指南](./installation.md)。

## 快速上手路线

第一次使用时，建议按以下顺序完成配置：

1. 打开左下角的“设置”。
2. 在“提供商”中添加模型服务地址和 API Key，并验证连接。
3. 在“模型”中创建至少一个语言模型，并设为默认模型。
4. 返回“项目”，新建项目或导入 TXT 旧稿。
5. 打开项目，创建卷和章节，开始写作。
6. 需要 Agent 时，在右侧 Agent 面板新建对话并描述任务。
7. 需要语义检索时，再配置 Embedding 模型并启用索引。

只进行手动写作不需要配置模型。Agent、自动摘要、模型整理导入内容等 AI 功能需要可用的语言模型；章节语义检索需要 Embedding 模型。

## 认识主界面

应用左侧主导航包含以下入口：

| 入口 | 用途 |
|---|---|
| 项目 | 创建、导入、搜索和管理小说项目 |
| 世界书 | 管理地点、规则、组织、物品和研究资料等设定条目 |
| 角色 | 管理人物档案、头像、描述和收藏 |
| 提示词 | 查看和编辑系统提示词链及版本 |
| 仪表盘 | 查看写作统计、模型调用和调用记录 |
| 设置 | 配置界面、模型、索引、工具权限、规则、技能和智能体 |

打开一个项目后，工作台通常分为三部分：

- 左侧：卷章树与笔记树。
- 中间：章节或笔记编辑器，可同时打开多个标签页。
- 右侧：Agent 会话、任务状态、工具调用和上下文入口。

各栏都可以收起。较窄窗口下，部分区域会改为抽屉或覆盖层。

## 配置模型服务

### 添加提供商

打开“设置 → 提供商”，选择“新建连接”：

1. 选择提供商类型；使用中转站或 OpenAI 兼容服务时选择“自定义 / 中转站”。
2. 填写服务 URL。官方服务可使用默认地址，中转站应填写其文档指定的 Base URL。
3. 填写 API Key。
4. 点击“验证连接”。
5. 验证成功后保存。

如果提供商不支持模型列表 API，界面可能无法自动列出模型。这并不一定表示连接不可用，可以在创建模型时手动输入准确的模型 ID。

### 创建语言模型

进入“设置 → 模型 → 语言模型”，选择“新建模型”：

1. 填写一个便于辨识的名称。
2. 选择刚创建的提供商。
3. 从列表选择模型，或手动输入模型 ID。
4. 将任务类型保持为“语言模型 (LLM)”。
5. 按服务商说明设置上下文长度和最大输出；不确定时不要修改高级采样参数。
6. 保存后，将常用模型设为“默认模型”。

建议同时指定一个“轻量模型”，用于标题生成、摘要等较轻任务。轻量模型可以与默认模型相同。

Agent 需要模型支持工具调用。若模型卡片提示似乎不支持工具调用，它可能只能生成普通文本，无法可靠读取或修改项目内容。

### 推理模型与中转站

对于支持推理强度的模型，OmniFic 会优先自动识别能力。如果中转站没有返回正确的模型 metadata，可以在模型设置中手动指定是否支持推理强度。详细说明见[模型推理能力](./features/model-reasoning.md)和[中转站供应商](./features/relay-provider.md)。

## 创建或导入项目

### 创建空白项目

在“项目”页点击“新建项目”：

1. 输入项目标题。
2. 可选填写简介并上传封面。
3. 创建后点击项目卡片进入工作台。
4. 在左侧新建卷，再在卷中创建章节。

项目页支持按名称搜索、按最近编辑/创建时间/名称排序，以及网格和列表两种视图。

### 导入 TXT 旧稿

在“项目”页点击“导入”，选择 TXT 文件。OmniFic 会尝试识别编码、卷标题和章节标题，并在写入前展示章节数量、总字数和章节预览。

如果没有识别到章节标题，全文会作为一个章节导入。建议先检查预览结果，再确认书名并开始导入。详细的标题识别规则见[TXT 小说分卷导入](./features/txt-volume-import.md)。

导入会创建新项目，不建议用它覆盖已有项目。重要旧稿应保留原始备份。

## 卷章与写作编辑

### 管理卷和章节

在项目工作台左侧选择“章节”：

- 新建卷后，可通过卷菜单修改名称、说明和顺序。
- 可在卷内新建章节，也可复制、重命名、移动或删除章节。
- 开启排序模式后可以拖动卷章，并在完成后保存顺序。
- 点击章节会在中间编辑器打开；通过上下文菜单可在新标签页打开。

删除卷、章节或项目属于不可逆操作。删除包含章节的卷前，界面会要求再次确认。

### 编辑与自动保存

章节编辑器支持常见富文本结构，包括标题、列表、引用和代码块。编辑内容会进入自动保存流程，请留意编辑器显示的“保存中”“已保存”或“保存失败”状态。

常用快捷键：

| Windows/Linux | macOS | 操作 |
|---|---|---|
| `Ctrl + S` | `Command + S` | 立即保存 |
| `Ctrl + F` | `Command + F` | 查找 |
| `Ctrl + H` | `Command + H` | 查找并替换 |

多标签页适合同时打开正文、提纲和参考笔记。可以锁定标签页、关闭其他标签页或关闭全部标签页。

### 使用笔记

切换左侧栏顶部的“章节 / 笔记”选项即可管理笔记：

- 创建多级分类和笔记。
- 移动、复制、重命名或删除笔记。
- 将大纲、时间线、伏笔表和研究资料与正文分开管理。
- 锁定不希望 Agent 修改的笔记。

章节或笔记可以从标签页、树菜单或编辑器选中文本处加入 Agent 会话上下文。

## 角色与世界书

### 维护角色

从主导航进入“角色”，先选择关联项目，再创建人物：

- 填写名称和人物描述。
- 上传并裁剪头像。
- 使用搜索、收藏、排序和多选管理大量角色。
- 将人物动机、关系、能力、口吻和禁忌写入描述，便于 Agent 检索和保持一致性。

角色名称应尽量稳定。频繁改名可能让旧章节、摘要或提示词中的引用难以匹配。

### 维护世界书

从主导航进入“世界书”，选择项目与世界书后创建条目。一个条目适合描述一个相对独立的主题，例如地点、势力、规则、物品、历史事件或研究资料。

条目可以启用或停用。Agent 默认只应把当前启用的条目视为有效设定；暂时废弃但不想删除的内容可以停用。

### 导入世界书与资料

世界书支持两类导入：

- SillyTavern JSON 世界书。
- Markdown、PDF、DOCX、PPTX 和 TXT 文档。

导入前会先解析并展示预览。选择“追加”会保留现有条目，同名条目可能被更新；选择“覆盖”会删除当前世界书已有条目后再导入，操作前务必备份。

文档导入可以选择使用模型优化名称、合并重复内容或拆分过长条目。模型整理会产生 API 调用和 Token 消耗。详细说明见[世界书多格式导入](./features/worldbook-import.md)。

## 使用 Agent 协作

### 使用前检查

Agent 正常工作至少需要：

1. 已验证的模型提供商。
2. 一个设为默认模型、且支持工具调用的语言模型。
3. 当前项目中有可读取的正文或资料。
4. “设置 → 工具权限”没有拒绝任务所需的工具。

Embedding 和 Rerank 不是基础对话的必需项，但没有 Embedding 时无法使用章节语义检索。

### 发起任务

在项目右侧 Agent 面板中新建对话，直接说明目标、范围和限制。例如：

> 阅读第一卷已有章节和萧炎的人物设定，检查第十二章的行为是否一致。先列出问题，不要修改正文。

需要 Agent 修改内容时，建议明确：

- 要处理的章节、卷或笔记。
- 希望保留的风格、视角和长度。
- 哪些设定是硬约束。
- 是只给建议，还是允许写入。
- 修改前是否需要先给计划或询问。

描述越具体，Agent 越容易选择正确的工具和上下文。

### 添加上下文

可以把章节、卷、笔记、角色、世界书条目或编辑器选中文本加入当前对话。显式加入的内容适合放置必须阅读的材料；其余资料可由 Agent 通过搜索和读取工具按需获取。

不要一次加入大量无关正文。过多上下文会增加 Token 消耗，也可能稀释真正重要的约束。

### 工具权限、审批与变更预览

在“设置 → 工具权限”中，每种工具都可以设置默认策略：

- 允许：Agent 可以直接调用。
- 询问：执行时需要你批准。
- 拒绝：Agent 不得调用。

对创建、编辑和删除内容的工具，首次使用建议选择“询问”。Agent 请求写入时，先检查工具名称、目标对象和变更预览，再批准或拒绝。

取消 Agent 运行不等于自动撤销已经成功写入的数据。重大修改前应备份项目数据，并尽量通过审批预览控制写入范围。

### 任务、目标和斜杠命令

Agent 面板会保留对话与任务历史。可使用 `/` 命令查看状态、切换模型和推理强度、维护持久任务目标或选择技能。

长期任务建议先设置清晰目标，使会话压缩或重新进入任务后仍能恢复核心方向。详细说明见[`/` 命令中心](./features/codex-slash.md)和[任务目标持久化](./features/task-goal.md)。

### 主智能体与子智能体

主智能体可以把检索、审阅或其他独立工作委派给已配置的子智能体。你可以在会话中查看子任务的排队、运行、等待输入、完成或失败状态。

子智能体配置位于“设置 → 智能体”。只有在任务确实可以独立拆分时，多智能体才会带来收益；简单修改使用单个 Agent 通常更直接。

## 摘要、索引与长上下文

### 摘要

章节摘要用于把正文压缩为更短的剧情与设定信息；区间摘要进一步概括连续章节。摘要适合帮助 Agent 快速理解长篇进展，但不能代替关键章节原文。

正文变化后，旧摘要可能变为过期状态。可在项目的摘要维护区域检查缺失、处理中、过期或失败的项目，并按需生成、更新或重试。

### 语义检索索引

启用章节语义检索前：

1. 在“设置 → 模型 → 嵌入模型”创建 Embedding 模型。
2. 将其设为默认嵌入模型。
3. 在“设置 → 索引”选择全部项目或指定项目启用。
4. 按需要设置自动更新策略、分块大小和重叠范围。
5. 首次启用或模型变化后构建索引。

更换默认 Embedding 模型会让已有索引失效，需要重新构建。Rerank 模型是可选项，用于对初步检索结果再次排序。

当 Agent 提示“索引未启用”“未配置嵌入模型”“索引需要重建”或“索引非最新”时，先处理对应状态，再重试语义搜索任务。

## 提示词、规则、技能与智能体

这些功能适合在基本工作流稳定后再调整：

- 提示词：修改会话、摘要、压缩和智能体使用的提示词链，保存为新版本并查看差异。
- 规则：维护跨会话需要遵守的创作或执行约束。
- 技能：启用内置技能或导入专门工作流程所需的技能包。
- 智能体：配置主智能体、子智能体、模型、工具、技能和可委派关系。

修改系统提示词和智能体配置可能显著改变 Agent 行为。建议每次只改一个目标，保留版本说明，并用小范围任务验证后再用于整部作品。

## 查看创作与模型数据

“仪表盘”包含多个视角：

- 写作：查看写作日历、活跃天数、字数变化和用户编辑/Agent 编辑/导入来源。
- LLM：查看调用次数、Token、延迟、首 Token 时间、模型分布和项目分布。
- 调用记录：查看单次调用状态；启用详细记录后，还可检查工具、输入和输出。

“设置 → 高级”中的调用详情记录会增加数据库占用，建议只在排查问题时开启。清空调用详情不会删除调用次数、Token 和耗时等汇总统计。

## 推荐工作流

### 从零开始一本新书

1. 创建项目和第一卷。
2. 在笔记中建立大纲、时间线和待解决问题。
3. 创建主要角色与核心世界书条目。
4. 写完若干章节后生成摘要。
5. 配置 Embedding 并建立索引。
6. 让 Agent 先做设定检查和建议，再逐步开放写入权限。

### 接续已有长篇

1. 备份原始 TXT 和资料。
2. 导入 TXT，检查卷章识别结果。
3. 导入或手动整理角色、世界观和研究资料。
4. 为已有章节生成摘要和检索索引。
5. 先让 Agent 只读分析人物、时间线和伏笔，再进行续写。

### 进行大范围修订

1. 先备份桌面数据目录。
2. 把修改目标和不可变设定写入任务目标或规则。
3. 要求 Agent 先列计划和受影响章节。
4. 将写入工具设为“询问”。
5. 分卷或分章节审批修改，完成后检查摘要和索引是否需要更新。

## 数据安全与隐私

- 正文和主要应用数据默认保存在本机 SQLite 中。
- 使用云端模型、中转站、Embedding 或 Rerank 服务时，请求中的相关上下文会发送给你配置的服务。
- API Key 和创作数据是否安全，取决于本机安全措施和所选服务商。
- 删除项目、卷章、角色、世界书条目或数据目录前应先备份。
- 0.8.1 仍处于 Alpha 阶段，不承诺旧 OpenFic 或 0.8.0 数据目录可以无损直接覆盖迁移。

备份路径和卸载残余位置见[安装与卸载指南](./installation.md)。

## 常见问题

### 首屏一直加载或显示初始化失败

点击界面的重试入口。如果仍失败，检查本地后端是否运行、端口是否被占用、代理是否影响本地连接，并查看桌面启动日志。桌面数据与日志目录见[安装与卸载指南](./installation.md)。

### Agent 可以聊天，但不会读取或修改内容

检查模型是否支持工具调用，并查看“设置 → 工具权限”是否拒绝了读取、搜索或写入工具。需要语义搜索时还要确认 Embedding 模型和索引状态。

### Agent 一直要求批准

对应工具的默认策略是“询问”。确认模型和任务可信后，可在“设置 → 工具权限”中调整；删除和大范围写入仍建议保留审批。

### 语义搜索没有结果

确认当前项目已启用索引、默认 Embedding 模型可用，并检查索引是否缺失、过期、失败或需要重建。普通标题搜索不依赖 Embedding。

### 内容没有保存

先查看编辑器保存状态并点击重试，不要立即关闭应用。检查磁盘空间、数据目录权限和本地后端状态。恢复正常后再次确认“已保存”。

### macOS 提示应用无法验证或需要手动更新

0.8.1 尚未使用 Developer ID 签名和 Apple 公证。首次打开和手动更新方法见[安装与卸载指南](./installation.md)。

### 我只想写作，不想使用 AI

可以。项目、卷章、笔记、角色和世界书等本地管理功能可以独立使用；不配置模型即可避免发起模型请求。
